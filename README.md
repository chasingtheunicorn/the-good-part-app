# The Good Part — the sheet

A prototype, live at **https://chasingtheunicorn.github.io/the-good-part-app/**

The companion app to *The Good Part*, a book about filming the one moment worth
showing someone. Say a sentence and it drafts your whole Day Sheet, then prompts
one thing at a time: plan the day, get six shots, post it, and seven days later
name the moment without looking at anything.

**No account, no server.** Every sheet is stored in your own browser, on your own
device, and never leaves it. Clearing your browser data clears your sheets, so
use Settings to export a backup if you care about them.

**Try it in thirty seconds.** Tap *Say my moment* and dictate something vague,
like "our trip to the coast," and watch the three checks fail with reasons. Then
try "the switch, first try, and the light holds" and the sheet appears complete.

This is a test build with everything unlocked. The shipping version is a native
app for iOS and Android, built from these same files with Capacitor: one-time
purchase, with a code in the book worth thirty days.

Source of record lives in a private repo; this one holds the built web app so
people can try it.
