The Good Part

Install the sheet on your Android phone

Build 15. The book's Day Sheet as an app: no account, no server, everything stays on the phone.

Download the appTheGoodPart.apk · about 5 MB
  1. Tap the button above on the phone. Chrome will warn that this kind of file can be harmful; choose Download anyway.
  2. Open the download. Pull down the notification shade and tap it, or open the Files app and tap TheGoodPart.apk.
  3. Allow the install. The first time, Android asks to let Chrome (or Files) install unknown apps. Tap Settings, switch Allow from this source on, then go back and tap Install.
  4. Open it. The icon is the ember dot on black. It runs without a connection.
This is a review build, signed for testing rather than through the Play Store, so Android treats it as an unknown app. If Play Protect asks, choose Install anyway. To update later, download the newer file the same way; it installs over the old one and keeps your sheets.

Prefer the web version? Open it in the browser. The build number is shown at the bottom of Settings in both.
