The Good Part

Install the sheet on your Android phone

Build 15. The book's Day Sheet as an app: no account, no server, everything stays on the phone.

Download the appTheGoodPart.apk · about 5 MB
  1. Tap the button above on the phone. If Chrome says the file might be harmful, choose Download anyway.
  2. Turn on the switch. Android will not install an app from outside the store until you allow Chrome to do it, once. Open Settings, tap the search box at the top, type unknown, and tap Install unknown apps. Pick Chrome and turn on Allow from this source.
  3. Open the download. Pull down the notification shade and tap it, or open Files (Samsung: My Files) → Downloads → TheGoodPart.apk. Tap Install.
  4. Open it. The icon is the ember dot on black. It runs without a connection.

Where the switch is, by phone

  • Samsung: Settings → Apps → the three dots (top right) → Special access → Install unknown apps → Chrome → on. Older Samsungs: Settings → Biometrics and security → Install unknown apps.
  • Pixel and most others: Settings → Apps → Special app access (sometimes under “See all apps” or “Advanced”) → Install unknown apps → Chrome → on.
  • If you opened the file from the Files app, allow Files (or My Files) instead of Chrome.
“Blocked by Play Protect”? Tap More details, then Install anyway. This is a review build signed for testing rather than through the Play Store, so Android treats it as an unknown app. To update later, download the newer file the same way; it installs over the old one and keeps your sheets.

Prefer the web version? Open it in the browser. The build number is shown at the bottom of Settings in both.
